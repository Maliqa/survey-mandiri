Aplikasi demo Android · versi __VERSION__
Marketplace survei lapangan.
Client (leasing, caleg, produk) memesan survei, surveyor terverifikasi mengerjakan, dana aman di escrow.
Unduh APK (Android 8.0+)
Cara instal
  1. Tap tombol unduh di atas.
  2. Buka file survey-mandiri-demo.apk dari notifikasi atau folder Download.
  3. Jika muncul peringatan, izinkan Instal aplikasi tidak dikenal untuk browser Anda.
  4. Buka aplikasi, lalu masuk dengan akun demo atau daftar akun baru.
